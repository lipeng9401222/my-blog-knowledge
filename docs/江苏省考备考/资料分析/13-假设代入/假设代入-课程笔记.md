# 13 假设代入

> 📌 **本章定位**：假设代入是一种**逆向验证**思想——不直接求增量，而是先"假设"一个值，算出对应的"计算增量"，再根据它与假设值的大小关系推断实际值落在哪一侧。两大用法：
> 1. **判断方向**（增量验算）：综合题里判断"是否超过/不足某值"
> 2. **代入选项精算**：选项差距极小时算出精确增量
>
> 材料来源：小P手写版「第十一课：假设代入」7页 + 课程讲义「第十三节 假设代入」3页 + 小P笔记，已合并去重。

## 一、判断方向（代入思想一 / 增量验算）

> 💡 **应用场景**：综合题（正误判断）中，判断**增量、基期、整体量、均值**是否超过 / 低于某个值。
>
> ⭐ **核心结论**：**实际增量位于"代入假设增量后得到的计算增量"那一侧。**
> - 当 r > 0：实际增量在**假设增量与计算增量之间**
> - 当 r < 0：实际增量在**计算增量更外侧**

### 1️⃣ 当增量 > 0（r > 0）

| 情形 | 推导链 | 结论 |
| --- | --- | --- |
| 实际增量 > 假设增量 | 假设增量偏小 → 假设基期偏大 → 计算增量偏大 | **计算增量 > 实际增量 > 假设增量** |
| 实际增量 < 假设增量 | 假设增量偏大 → 假设基期偏小 → 计算增量偏小 | **计算增量 < 实际增量 < 假设增量** |

> ✅ 一句话：**实际增量夹在中间**，靠近哪边算哪边。

**证明示例**（现期 200，增速 10%，实际增量 18.18）：

- 问"是否超过 20"：假设增量 20 → 假设基期 180 → 计算增量 180×10% = **18 < 18.18** → 实际增量在 18 与 20 之间 → 没超过
- 问"是否不足 15"：假设增量 15 → 假设基期 185 → 计算增量 185×10% = **18.5 > 18.18** → 实际增量在 15 与 18.5 之间 → 不是不足

### 2️⃣ 当增量 < 0（r < 0，看绝对值）

| 情形 | 推导链 | 结论 |
| --- | --- | --- |
| 实际增量 > 假设增量 | 假设增量偏小（绝对值）→ 假设基期偏小 → 计算增量偏小 | **实际增量 > 计算增量 > 假设增量** |
| 实际增量 < 假设增量 | 假设增量偏大（绝对值）→ 假设基期偏大 → 计算增量偏大 | **实际增量 < 计算增量 < 假设增量** |

> ⚠️ 注意：增量 < 0 时，实际增量在**计算增量外侧**，与 r > 0 的规律不同！

**证明示例**（现期 200，增速 −10%，实际增量 −22.22）：

- 问"减少量是否超过 20"：假设 −20 → 基期 220 → 计算 220×(−10%) = −22 → 实际 −22.22 在 −22 外侧 → 超过 20 ✅
- 问"减少量是否低于 30"：假设 −30 → 基期 230 → 计算 230×(−10%) = −23 → 实际 −22.22 在 −23 外侧 → 低于 30 ✅

### 3️⃣ 三种拓展判断（基期 / 整体量 / 均值）

| 判断对象 | 操作 | 原理 |
| --- | --- | --- |
| **基期** | 假设基期 → 算计算现期 = 基期×(1+r) → 与实际现期比 | 计算现期 < 实际现期 → 假设基期偏小 → 实际基期更大 |
| **整体量** | 假设整体 → 算部分 = 整体×占比 → 与实际部分比 | 计算部分 < 实际部分 → 假设整体偏小 → 实际整体更大 |
| **均值** | 假设均值 → 算总量 = 均值×份数 → 与实际总量比 | 计算总量 < 实际总量 → 假设均值偏小 → 实际均值更大 |

### 例题（判断方向）

> 📝 **【重型货车】** 2019 年 1-11 月，重型货车产销分别完成 106.1 万辆和 108.2 万辆，同比分别增长 4.7% 和 1.6%。
> 问：销量同比增量**超过 2 万辆**？
> A. 正确　**B. 错误 ✅**
>
> 解析：假设增量 = 2 → 假设基期 = 108.2 − 2 = 106.2 → 计算增量 = 106.2 × 1.6% ≈ 1.7 < 2
> 计算增量 < 假设增量 → 实际增量夹在中间 → 实际增量 < 2，没超过。

> 📝 **【H省市场主体】** 2022 年，H 省各类市场主体总数 734.98 万户，同比增长 13.5%。
> 问：同比增长**超过 90 万户**？
> A. 正确　**B. 错误 ✅**
>
> 解析：假设增量 = 90 → 假设基期 = 734.98 − 90 = 644.98 → 计算增量 = 644.98 × 13.5% ≈ 87 < 90
> 计算增量 < 假设增量 → 实际增量 < 90，没超过。

> 📝 **【S省建筑业】** 2020 年末 S 省资质以上建筑业企业完成总产值 5113.6 亿元，同比增长 9.9%。
> 问：同比增量**超过 460 亿元**？
> **A. 正确 ✅**　B. 错误
>
> 解析：假设增量 = 460 → 假设基期 = 5113.6 − 460 = 4653 → 计算增量 = 4653 × 9.9% = 465.3 − 4.65 ≈ **460.7 > 460**
> 计算增量 > 假设增量 → 实际增量在两者之间且 > 460 → 超过 ✅
> 💡 技巧：×9.9% = ×(100−1)%，拆分速算。

> 📝 **【OPPO 出货量·情形一】** 2021 年第一季度，OPPO 智能手机出货量 39.6 百万台，同比增长 −27%。
> 问：同比减少**不足 20 百万台**？
> **A. 正确 ✅**　B. 错误
>
> 解析（r < 0）：假设增量 = −20 → 假设基期 = 39.6 + 20 = 59.6 → |计算增量| = |59.6 × (−27%)| ≈ 16.1 < 20
> 假设增量绝对值偏大 → 实际减少量 < 计算减少量 < 20 → 确实不足 20 ✅

> 📝 **【OPPO 出货量·情形二】** 同上。问：同比减少**不足 10 百万台**？
> A. 正确　**B. 错误 ✅**
>
> 解析：假设增量 = −10 → 假设基期 = 49.6 → |计算增量| = |49.6 × (−27%)| ≈ 13.4 > 10
> 计算增量 > 假设增量，实际在计算增量外侧 → 实际减少量 > 13.4 > 10 → "不足 10"错误 ✅

> 📝 **【美术馆·判断基期】** 2016 年全年全国国有美术馆共举办展览 6146 次，比上年增长 16.8%。
> 问：2015 年**超过 5000 次**？
> **A. 正确 ✅**　B. 错误
>
> 解析：假设基期 = 5000 → 计算现期 = 5000 × (1+16.8%) = 5000 + 840 = 5840 < 实际现期 6146
> 说明假设基期偏小 → 实际基期 > 5000 ✅

> 📝 **【残疾儿童·判断整体量】** 2022 年，A 省残疾儿童接受康复救助人数为 3.57 万人，占全国的 8.84%，比 2020 年增加 2090 人。
> 问：2022 年全国接受康复救助的残疾儿童数**超过 40 万人**？
> **A. 正确 ✅**　B. 错误
>
> 解析：假设全国 = 40 万 → 计算 A 省 = 40 × 8.84% = 3.536 万 < 实际 3.57 万
> 说明假设总量偏小 → 实际总量 > 40 万 ✅

> 📝 **【人均GDP·判断均值】** 2023 年 A 市 GDP 为 17421 亿元，常住人口 954.7 万人。
> 问：人均 GDP **超过 18 万元**？
> **A. 正确 ✅**　B. 错误
>
> 解析：假设人均 = 18 → 计算 GDP = 954.7 × 18 = (1000 − 45.3) × 18 = 18000 − 810 = 17190 < 实际 17421
> 说明假设均值偏小 → 实际人均 > 18 万 ✅
> 💡 速算：954.7×18 = 955×18 → 1910×9 = 17190（×2 再 ÷2 凑整）。

## 二、代入选项精确计算（代入思想二）

> 💡 **应用场景**：增量 / 基期计算中，**选项差距很小**（误差在 2% 以下）且**增速小**。
>
> ⭐ **核心思路**：
> - 实际增量 ≈ 代入计算增量
> - 借助差距很小的选项确定假设基期（**尽可能让基期尾数变成 0，好算**）
> - 再借助**增速的缩小效应**把选项误差缩小，得到非常准确的增量

### 操作步骤

1. **选代入值**：取选项区间内一个值作假设增量，使"现期 ± 假设增量"得到**整十整百的假设基期**
2. **算计算增量**：计算增量 = 假设基期 × r（老实计算，不要四舍五入）
3. **误差修正**：计算增量与假设增量的差为 d，则修正量 = **d × r**，向实际值方向加/减
4. 得出精确增量，锁定选项

### 📐 误差原理

$$\text{假设基期}\times(1+r)=\text{假设增量（对应现期）}$$
$$(\text{假设基期}+d)\times(1+r)=\text{实际增量（对应现期）}$$

> 实际比假设只多了 **d × r**。由于 r 非常小，这个修正量极小，所以**计算增量与假设增量之间的差距 × r 就是误差**，可精确修正。

> ⚠️ **注意**：
> - 假设代入一般适用于**综合题的判断**（是否超过/低于）；**单一题型正常计算**即可。
> - 代入值必须**在选项区间范围内**——例如 2012 山东题不建议为了抹尾数直接代 2591（不在选项区间内）；保守做法代 2607，仍能得出答案 2606。
> - r < 10% 时可**化除为乘**辅助估算。

### 例题（代入选项精算）

> 📝 **【2019 山西】** 2018 年 C 国全年粮食产量 65789 万吨，比上年减少 371 万吨，减产 0.6%。其中，夏粮产量 13878 万吨，减产 2.1%。
> 2017 年夏粮产量与 2018 年夏粮产量相差：
> A. 291 万吨　B. 296 万吨　C. 289 万吨　**D. 298 万吨 ✅**
>
> 解析：选项差距极小，代入 **292**（选项折中，且 13878 + 292 = 14170 尾数变 0）
> 假设基期 = 14170 → 计算增量 = 14170 × 2.1% = **297.57**
> 代入增量比计算增量小 5.5 → 补上 5.5 × 2.1% ≈ 0.12 → 297.57 + 0.12 ≈ **297.7 → 选 D**
> 💡 注：这类题选最近的选项即可，误差特别小（选项 298 存在四舍五入误差，计算结果甚至比答案还准）。

> 📝 **【A社区·21055人】** 2022 年，A 社区居民 21055 人，同比增长 6.2%。增长了多少人？
> A. 1221　B. 1225　**C. 1229 ✅**　D. 1233
>
> 解析：代入 **1225** → 假设基期 = 21055 − 1225 = 19830
> 计算增量 = 19830 × 6.2% = 1189.8 + 39.6 = **1229.4**
> 代入增量比计算增量小 4.4（即假设基期多了 4.4）→ 减去 4.4 × 6.2% ≈ 0.27 → 1229.4 − 0.3 ≈ **1229.1 → 选 C**

> 📝 **【A社区·1173人】** 2022 年，A 社区居民 1173 人，同比增长 6.9%。增长了多少人？
> A. 68　B. 71　C. 73　**D. 76 ✅**
>
> 解析：代入 **73** → 假设基期 = 1173 − 73 = 1100
> 计算增量 = 1100 × 6.9% = **75.9**，比代入值大 2.9
> 减去 2.9 × 6.9% ≈ 0.2 → 75.9 − 0.2 = **75.7 → 选 D**

> 📝 **【2013 年 1-3 月 工业企业】** 外商及港澳台商投资规模以上工业企业主营业务收入 54066.7 亿元，同比增长 8.0%。同比约增加了多少亿元？
> A. 3965　**B. 4005 ✅**　C. 4135　D. 4325
>
> 解析：代入 **3966** → 假设基期 = 54066 − 3966 = 50100
> 计算增量 = 50100 × 8% = **4008**，比代入值大 42
> 减去 42 × 8% ≈ 3.4 → 4008 − 3.4 ≈ **4005 → 选 B**
> 💡 也可代 4006：基期 50060，计算 4004.8，修正 −1.2×8% ≈ −0.1 → 4004.7 ≈ 4005，殊途同归。

> 📝 **【2012 山东】** 2010 年增值税收入 21091.95 亿元，同比增长 14.1%，比上年同期增速加快了 11.4 个百分点。
> 2010 年全国增值税比 2009 年增长了约多少亿元？
> A. 2610　B. 2608　**C. 2606 ✅**　D. 2604
>
> 解析：选项只差 2（误差 0.07%），代入 **2612** → 假设基期 = 21092 − 2612 = 18480
> 计算增量 = 18480 × 14.1% = **2605.68**，比代入值小 6.3
> 加上 6.3 × 14.1% ≈ 0.9 → 2605.68 + 0.9 ≈ **2606.5 → 选 C**
> ⚠️ 不建议代 2591（不在选项区间内）；保守可代 2607：基期 18485，计算 2606.4 → 同样选 C。

> 📝 **【2018 重庆】** 2018 年 1-5 月，粮油、食品类商品零售额 5505 亿元，同比增长 9.2%。同比增加多少亿元？
> A. 70　B. 70.6　**C. 463.8 ✅**　D. 465
>
> 解析：A、B 是仅 5 月的量级，先排除（注意题目问 1-5 月）。
> 代入 **465** → 假设基期 = 5505 − 465 = 5040
> 计算增量 = 5040 × 9.2% = **463.68**，比代入值小 1.32
> 加上 1.32 × 9.2% ≈ 0.12 → 463.68 + 0.12 = **463.8 → 选 C**

## 三、综合判断 + 精算混合例

> 📝 **【2023 江西】** 2021 年，全国城市供水总量 673.34 亿立方米，同比增长 6.96%；城市供水管道长度 105.99 万公里，同比增长 5.26%。
> 2021 年全国城市供水管道长度比 2020 年增长约：
> A. 5 万公里　**B. 5.3 万公里 ✅**　C. 5.6 万公里　D. 6 万公里
>
> 解析：假设增量 = 5.99 → 假设基期 = 105.99 − 5.99 = **100**（凑整好算）
> 计算增量 = 100 × 5.26% = **5.26 < 假设增量 5.99**
> 说明假设增量偏大 → 计算增量 5.26 < 实际增量 < 假设增量 5.99，且**更靠近计算增量** → 选 B（5.3）
> 💡 辅助验证（r < 10% 化除为乘）：Δ < 106 × 5.26% ≈ 5.26 + 6×5.26% ≈ 5.57，进一步排除 C、D。

## 📋 本章要点速记

| 要点 | 内容 |
| --- | --- |
| **总原则** | 实际增量位于"代入假设增量后得到的计算增量"那一侧 |
| **r > 0** | 实际增量**夹在**假设增量与计算增量**之间** |
| **r < 0** | 实际增量在**计算增量外侧**（看绝对值） |
| **判断基期/整体/均值** | 假设 → 反算另一边 → 与实际比，偏小则实际更大 |
| **精算适用** | 选项差距 < 2%、增速小 |
| **精算步骤** | 凑整基期 → 算计算增量 → 误差修正 = 差值 × r |
| **代入值选取** | 必须在选项区间内；优先让基期尾数变 0 |
| **适用边界** | 综合题判断用假设代入；单一题型正常计算 |
